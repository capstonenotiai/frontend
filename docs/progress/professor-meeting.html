프로젝트 개요

문제

학교 공지, 장학금, 공모전, 대외활동, 취업 정보가 여러 사이트에 흩어져 있고, 공지 본문마다 신청 기간과 마감일을 직접 찾아 캘린더에 옮겨야 합니다. 마감을 놓치기 쉽습니다.

해결

공지를 자동 수집하고, 파인튜닝한 LLM이 일정 정보를 추출해 Google Calendar에 등록합니다. AI Planner가 사용자 성향에 맞춰 무엇부터 챙길지 추천합니다.

주요 설계 판단

마감일은 늦게 알려주지 않는다

마감일을 실제보다 늦게 알려주면 기회를 놓칩니다. 그래서 정확도 하나보다 위험한 방향의 오류를 따로 측정하고, 불확실한 건은 검토 대기로 보냅니다.

작은 모델 + 필요할 때만 큰 모델

날짜가 불확실한 약 10%만 GPT-4o-mini로 다시 처리합니다. 비용을 줄이면서 재학습 없이 정확도를 보완했습니다.

API Key는 서버에만

브라우저에서 LLM을 직접 호출하지 않고 Cloudflare 서버 함수를 거칩니다. 시스템 프롬프트도 서버에서만 관리합니다.

모드를 설정 데이터로 분리

AI 모드와 관심 분야를 코드가 아닌 설정 파일로 관리해, 최종 모드가 정해지면 화면 수정 없이 교체할 수 있습니다.
